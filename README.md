# Task List API with Database

A FastAPI based REST API with SQLite database persistance using SQLAlchemy ORM.

## Features
- Create tasks 
- Delete tasks 
- Mark tasks as done 
- List all tasks with their status and id
- Check your last created tasks 

## Technologies
- Python 3 
- FastAPI
- Uvicorn
- Pydantic
- SQLAlchemy ORM
- SQLite

## Live Demo
https://api-fastapi-db-production.up.railway.app/docs

## How to run

Run the script:

pip install -r requirements.txt

uvicorn main:app
